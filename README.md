Entry for [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) on make.fun.

`main.ts` (Node 22, no dependencies) writes one sentence — at most 220
characters — pitching a ridiculous invention that fixes a tiny everyday
annoyance, to `/output/entry.txt`. The invention: a pocket-sized diplomat
that negotiates with your washing machine for the missing sock.

Run it with:

```sh
node main.ts
```
